## 1. Feature Summary & Goal

- **Objective:** Replace mock Kanban data with real Supabase database reads and Server Actions, implementing fractional position indexing for single-row drag-and-drop moves and persistent ordering.
- **Components:**
  - `src/features/kanban/lib/position.ts`: Fractional indexing helper using `generateKeyBetween` from `fractional-indexing`.
  - `src/features/kanban/types.ts`: Strongly typed interfaces (`KanbanTask`, `KanbanColumn`, `KanbanBoardData`, `TaskPriority`).
  - `src/features/kanban/actions.ts`: Server Actions for `getBoardAction`, `createTaskAction`, `moveTaskAction`, `deleteTaskAction`, and `updateTaskAction`.
  - `src/features/kanban/components/kanban-board.tsx`: TanStack React Query connected board with optimistic cache updates on drag events and single-row position writes.
  - `src/features/kanban/components/new-task-dialog.tsx`: Dynamic task creation dialog targeting board columns with title, priority, due date, and description.
  - `src/features/kanban/components/task-card.tsx` & `board-column.tsx`: Refactored presentation components displaying task assignees, due dates, and priority indicators.
