# P3MD Social Integration

One-liner integration system for the P3MD social project: role-based email, agenda calendar, kanban, talent screening, and a read-only MCP API that lets AI agents summarize what is going on.

Built on [Kiranism/next-shadcn-dashboard-starter](https://github.com/Kiranism/next-shadcn-dashboard-starter) (MIT) and Supabase.

## Start here

**→ [README_AI_AGENT.md](./README_AI_AGENT.md)**

That file is the gateway for humans and AI agents alike (Claude Code, Hermes Agent and any other harness). The frontend, backend and database architecture folders, the task list, the agent contract and the tooling (ECC, graphify, Obsidian sync, agent history) are linked from there.
