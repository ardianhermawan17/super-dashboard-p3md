## 3. Key Decisions & Rationale

| Decision | Rationale | Alternatives Considered |
|---|---|---|
| husky@9.x with `core.hooksPath=.husky` | Versioned hooks dir + `prepare` bootstrap; survives clones | Manual `.git/hooks` script (lost on clone) |
| Hook runs full `bun run agent:check` (sync + context) | Matches accept line; catches invalid entries AND stale context | Only `obsidian-sync --check` (misses stale `.hermes.md`) |
| `#!/usr/bin/env sh` shebang | Git-for-Windows can't spawn shebang-less hooks via hooksPath | No shebang (broke on this machine) |

### Verification Commands

