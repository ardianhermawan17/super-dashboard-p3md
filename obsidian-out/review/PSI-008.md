## 3. Key Decisions & Rationale

| Decision | Rationale | Alternatives Considered |
|---|---|---|
| Ports 54370-54379 instead of defaults | Windows Hyper-V reserved port range blocked 54321-54329 and 54416-54515 | Fighting Hyper-V exclusion range (unreliable); custom range above 54370 (stable) |
| Roles/groups NOT seeded in seed.sql | M1 migration (PSI-012) inserts `admin`, `all-members`, permissions itself — seeding them would cause duplicate errors | Seeding them anyway (would require PSI-012 to be aware of seed ordering) |
| `seed.sql` uses fixed user IDs (0001-0004) | Enables deterministic references in test data | Auto-generated UUIDs (harder to write test assertions against) |
| Full database docs review against live Postgres | Catches discrepancies between docs and actual DB behaviour before they reach production | Skipping review (would miss M9's missing RLS — a HIGH-severity finding) |
