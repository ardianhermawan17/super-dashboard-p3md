## 1. Feature Summary & Goal

- **Objective:** Implement the `google-calendar` Edge Function `/sync` pull endpoint that pulls events from linked Google Calendars on a recurring 15-minute cron schedule and mirrors them into `public.events` with role/group audience bindings.
- **Edge Function:** `supabase/functions/google-calendar/index.ts` + `mapper.ts`
- **Shared Helpers:**
  - `supabase/functions/_shared/google.ts`: JWT RS256 token signer for Service Account credentials and `gfetch` client.
  - `supabase/functions/_shared/internal.ts`: `assertInternal(req)` comparing Bearer tokens with `INTERNAL_FN_SECRET`.
- **Sync Logic:**
  - Queries `google_calendars` for enabled calendars with `direction in ('pull', 'both')`.
  - Paginates `GET /calendar/v3/calendars/{calendarId}/events?singleEvents=true&timeMin=<now-30d>&timeMax=<now+180d>&maxResults=2500`.
  - Maps fields: all-day dates mapped to `00:00:00+07:00` in Asia/Jakarta; recurring instances expanded; `RRULE:` prefix stripped.
  - Filters out `cancelled` status and events with `extendedProperties.private.p3md_event_id` (preventing sync loops for our own pushes).
  - Calls `public.upsert_google_event` RPC to write `source = 'google'`, `created_by = null`, link row, and audience binding.
  - Calls `public.prune_google_events` RPC to purge removed/cancelled events in the active sync window.
  - Updates `last_synced_at` and `last_error` on `public.google_calendars`.
