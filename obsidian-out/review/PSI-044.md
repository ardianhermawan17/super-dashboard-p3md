## 1. Feature Summary & Goal

- **Objective:** Implement private, unauthenticated ICS calendar subscription feed route and UI subscription modal with token rotation.
- **Components:**
  - Route: `GET /api/calendar/feed/[token]` resolving user ID via service client and querying `events_for_user()` RPC for date window [now - 30d, now + 180d].
  - RFC 5545 VCALENDAR generation via `ics` standard library.
  - Server Actions: `getCalendarFeedTokenAction()` and `rotateCalendarFeedTokenAction()` in `src/features/calendar/actions.ts`.
  - UI Modal: `CalendarFeedDialog` in `src/features/calendar/components/calendar-feed-dialog.tsx` allowing one-click copy and secure token invalidation/rotation.
