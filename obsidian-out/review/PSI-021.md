## 1. Feature Summary & Goal

- **Objective:** Establish the installable PWA shell with standalone display, web manifest, responsive/maskable icons, and a lean service worker for web push delivery and notification click navigation.
- **Components:**
  - `src/app/manifest.ts`: Serves `/manifest.webmanifest` configured with `start_url: '/dashboard/notifications'`, dark theme colors, and icon definitions.
  - Icons: `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, and `badge-72.png` in `public/icons/`.
  - Service Worker (`public/sw.js`): Push event listener rendering system notifications with action payload URLs, and `notificationclick` handler focusing or navigating the PWA window.
  - `next.config.ts`: Custom headers serving `/sw.js` with `no-cache, no-store, must-revalidate`.
  - Registration: `ServiceWorkerRegister` component mounted globally in root layout.
