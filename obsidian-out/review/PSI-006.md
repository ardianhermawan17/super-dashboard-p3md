## 4. Expected Output & Verification Runbook

### Verification Commands

```bash
# 1. Run sync — generates Board.md
bun run obsidian:sync
ls obsidian-out/Board.md

# 2. Run check on clean state — exit 0
bun run agent:check
echo $?   # 0

# 3. Run check with stale .hermes.md — exit 1

bun run agent:check   # on an invalid entry, exits 1
```
