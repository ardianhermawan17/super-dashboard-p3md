## 1. Feature Summary & Goal

- **Objective:** Mobile-first notification dashboard and real-time live notification bell popover in the app header.
- **Components:**
  - Realtime Hook (`useNotificationFeed`): Subscribes to Postgres CDC changes on `public.notifications` for the logged-in `userId`.
  - Notification Store (Zustand): Centralized state with optimistic mark read, mark all read, and live unread counter.
  - Notification Center (`/dashboard/notifications`):
    - Mobile-first quick navigation buttons (Agenda Today, Role Mail, Kanban Board).
    - Grouped list (Today vs Earlier) with unread prioritisation.
    - Category filtering dropdown (`mail.received`, `event.*`, `task.*`, `digest.*`, `document.*`, `system`).
    - Mark all as read action & single item deep-links.
  - Live Header Bell (`NotificationCenter` popover): Unread badge counter, latest 5 notifications preview, inline mark-read, and deep links.
