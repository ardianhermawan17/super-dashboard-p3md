## 1. Feature Summary & Goal

- **Objective:** Provide robust session claims parsing via `getSession()`, route and action guarding via `requirePermission()`, and reactive permission-filtered navigation across the sidebar and command bar (`visibleNav`, `useFilteredNavGroups`).
- **Contract Guardrails:** Authorize strictly by permission key (C-17). Never check role names directly in the application code.

---

## 2. Acceptance Criteria & Status

| # | Criterion | Status |
|---|---|---|
| 1 | `getSession()` returns roles, groups, and permissions from JWT claims | ✅ Implemented with React `cache` and `@/lib/supabase/server` |
| 2 | `requirePermission()` guards pages and actions | ✅ Implemented in `@/lib/auth/require` (redirects to sign-in if unauthenticated, `notFound()` if unauthorized) |
| 3 | Sidebar and Kbar hide items without required permission | ✅ `useFilteredNavGroups` dynamically filters navigation groups based on user claims permissions |
