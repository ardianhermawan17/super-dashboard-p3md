## 3. Key Decisions & Rationale

| Decision | Rationale | Alternatives Considered |
|---|---|---|
| Root-level `CLAUDE.md`, `AGENTS.md`, `.hermes.md` | Every AI agent reads these at session start; putting them at the root of the repo ensures no agent misses the gateway regardless of CWD | Keeping the gateway only in `README_AI_AGENT.md` (agents don't automatically read it); placing them under `docs/` (agents may not find them) |
| `AGENTS.md` carries both template conventions + P3MD rules | Single file any agent can grep; avoids splitting conventions across `frontend-architecture/AGENTS.md` and a root file | Leaving conventions only in the frontend subdirectory (Hermes sees it via `.hermes.md` but Claude Code would need an explicit `@` reference) |
| `.hermes.md` tracked in git | Acceptance criteria required it committed so the generated snapshot is versioned alongside the sources it merges | Keeping `.hermes.md` in `.gitignore` (generated file; but then every `bun run agent:context` produces an uncommitted diff, and Hermes has no way to verify the generated file matches the sources) |
| ECC Agentshield scan (`npx ecc-agentshield scan --path .`) deferred | ECC is not yet installed in the repo (PSI-009); the acceptance criteria referencing it is forward-looking | Installing ECC as part of PSI-004 (blocked on `human` owner for PSI-009) |
