## 1. Feature Summary & Goal

- **Objective:** Deliver the Role & Group Mail inbox interface (`/dashboard/mail`) built on the chat split-view layout.
- **Components:**
  - Audience Channels Sidebar: Groups conversations by target role (`to:<role>`) or target group (`to:group:<group>`).
  - Message Inspector: Displays sender metadata, subject, Markdown rendered message content, and status badges.
  - Per-recipient Delivery Breakdown: Lists delivery states (`pending`, `sent`, `delivered`, `bounced`, `failed`) with member profile names while strictly preserving privacy by omitting raw email addresses.
  - Server Actions in `src/features/mail/actions.ts` for database query and delivery joins.
