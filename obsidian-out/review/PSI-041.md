## 1. Feature Summary & Goal

- **Objective:** Port calendar onto Base UI and shadcn components without Radix `components/ui` imports, `asChild`, or react-dnd overhead.
- **Components:**
  - `src/features/calendar/types.ts`: `CalendarEvent`, `CalendarViewType` (month, week, day, agenda), `EventAudience`.
  - `src/features/calendar/actions.ts`: `getCalendarEventsAction()` joining `public.events` and `public.event_audience`, `deleteEventAction()`.
  - `src/features/calendar/components/calendar-header.tsx`: View switcher Tabs, Prev/Next navigation, Today button.
  - `src/features/calendar/components/month-view.tsx`: 7x5/6 month grid with day number bubbles and event badges.
  - `src/features/calendar/components/week-view.tsx`: 7-day hourly grid with event blocks.
  - `src/features/calendar/components/day-view.tsx`: Single-day hourly view.
  - `src/features/calendar/components/agenda-view.tsx`: Chronological event list with date cards.
  - `src/features/calendar/components/calendar-view.tsx`: Orchestrator managing view state and event inspection modal.
  - `src/app/dashboard/calendar/page.tsx`: Route page fetching calendar events and rendering the UI.
