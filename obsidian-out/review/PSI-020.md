## 1. Feature Summary & Goal

- **Objective:** Deploy Migration M2 establishing notifications, push subscriptions, user notification preferences, and internal webhook dispatch pipeline.
- **Components:**
  - `public.internal_post()`: Centralized secure HTTP dispatcher using `pg_net` and Vault secrets.
  - `public.notifications`: Notification items with check constraints, read/pushed tracking, and RLS.
  - `public.push_subscriptions`: Web push endpoints and VAPID keys.
  - `public.notification_prefs`: User push opt-in/opt-out toggles per notification type.
  - RPCs: `notify()`, `register_push_subscription()`, `push_targets()`, `mark_pushed()`.
  - Triggers & Automation: Statement-level trigger `notifications_dispatch` firing HTTP POST to `/api/push/dispatch`, Supabase Realtime publication, and 90-day retention cron job.
