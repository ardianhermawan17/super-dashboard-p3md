## 1. Feature Summary & Goal

- **Objective:** Implement the server-side Web Push dispatch route (`POST /api/push/dispatch`) authenticated via internal secret.
- **Components:**
  - Route: `src/app/api/push/dispatch/route.ts` running on Node.js runtime (`runtime = 'nodejs'`).
  - Auth: Rejects requests that do not carry `Authorization: Bearer <INTERNAL_FN_SECRET>`.
  - RPC query: Queries `public.push_targets(p_ids)` to retrieve filtered endpoints and payload parameters.
  - Concurrency Pool: Dispatches notifications via `web-push` using a worker queue with concurrency cap (20 workers).
  - Pruning: Identifies 404/410 Gone status codes from push services and deletes invalid subscriptions from `public.push_subscriptions`.
  - Confirmation: Invokes `public.mark_pushed(p_ids)` to timestamp notifications.
